# Tailwind 스타일링 규칙

- 스타일은 Tailwind 유틸리티 클래스로 쓴다. 인라인 `style` 과 별도 CSS 는 꼭 필요할 때만 쓴다.
- **모바일 우선**으로 쓴다. 기본 클래스가 모바일이고 `sm:`, `md:`, `lg:` 로 넓은 화면을 덧붙인다. 모바일 폭에서 깨지는지 확인한다.
- 같은 클래스 묶음이 3번 이상 반복되면 컴포넌트(버튼, 입력, 카드)로 뽑는다.
- 색상, 간격, 글자 크기는 프로젝트의 디자인 토큰(`tailwind.config`) 값을 쓰고, 임의 값(`w-[137px]`)은 최소로 한다.
- 클래스 조건부 결합은 `clsx` 같은 도구로 읽기 쉽게 쓴다. 문자열 이어붙이기로 클래스 이름을 만들지 않는다. (Tailwind 가 인식하지 못한다)
- 포커스·호버·비활성 상태를 만든다. (`focus-visible:`, `hover:`, `disabled:`)
- 색만으로 의미를 전달하지 않고, 글자 대비를 충분히 둔다.
