# 회고: 하네스 개선 후보 뽑기

## 절차
1. **재료 모으기**: 이번 세션의 대화, 최근 커밋(`git log -20`), 사용자가 고쳐 달라고 한 지점을 훑는다.
2. **분류**
   - 반복해서 틀린 것 → **규칙(rule)** 후보
   - 3번 이상 반복한 작업 절차 → **스킬(skill)** 후보
   - 부탁으로는 불안한 위험 행동 → **훅(hook)** 후보
3. **후보표를 보여준다.** 종류, 이름, 내용, 근거(어느 장면에서 나왔는지)를 적는다. 근거 없는 후보는 넣지 않는다.
4. 사용자가 고른 것만 만든다. 규칙은 `~/.claude/rules/`(공통) 또는 프로젝트 `.claude/rules/` 중 알맞은 곳에 둔다.
5. 프로젝트에 남길 학습 기록이 있으면 `.dev/learnings/` 에 정리한다. (문제, 적용한 패턴, 검증 방법)
6. 새로 만든 파일은 `harness-audit` 으로 기존 규칙과 충돌하지 않는지 한 번 확인한다.
