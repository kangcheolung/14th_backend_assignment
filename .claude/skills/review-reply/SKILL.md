# 리뷰 반영

## 절차
1. **코멘트 수집**: `gh pr view <번호> --comments`, 줄 단위 코멘트는 `gh api repos/{owner}/{repo}/pulls/<번호>/comments`
2. **분류**: 수정 필요 / 질문 / 제안 / 확인만 필요한 것으로 나눈다.
3. **대응표를 보여준다.** 항목마다 `파일:줄`, 코멘트 요약, 대응 방향, 답글 초안을 적는다.
   - 동의하지 않는 의견은 무조건 수용하지 말고 근거를 들어 답글 초안을 쓴다.
4. 사용자가 고른 항목만 코드를 고친다. 수정은 `commit-plan` 으로 확인받고 커밋한다.
5. 답글 게시(`gh pr comment`, 줄 코멘트 답글)는 **초안을 확인받은 뒤에** 한다.
6. 반영하지 않은 항목과 이유를 마지막에 정리한다.
