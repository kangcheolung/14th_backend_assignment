# 검증

## 절차
1. **명령 찾기**: 프로젝트 `CLAUDE.md` 의 명령을 우선한다. 없으면 감지한다.
   - `build.gradle` 이 있으면 `./gradlew build` (또는 `test`)
   - `package.json` 이 있으면 `scripts` 의 `build`, `lint`, `test`
   - 모노레포면 `backend/`, `frontend/` 를 각각 실행한다.
2. **순서대로 실행**: 빌드 → 테스트 → 린트. 앞에서 실패하면 뒤는 이유를 밝히고 멈추거나 계속할지 판단한다.
3. **결과 정리**
   - 통과: 명령과 결과 숫자를 적는다. (예: `./gradlew test` → 24 passed, 0 failed)
   - 실패: 첫 실패의 핵심 원인(로그 3~5줄), 해당 파일과 줄, 고칠 방향을 적는다.
4. 실패를 고치는 일은 요청이 있거나 원래 작업의 일부일 때만 한다.

## 지키는 것
- 실제로 실행한 것만 통과했다고 말한다. 실행하지 못한 항목은 "실행하지 못함"으로 적는다.
- 실패한 출력을 줄이거나 숨기지 않는다.
